# brewns — Specialty Coffee House

A beautifully crafted website for a specialty coffee house in San Francisco.

## Features

- 🎨 Modern, responsive design with smooth animations
- ☕ Interactive menu with 3D effects
- 📍 Location showcase with scroll-based interactions
- ⚡ Smooth scroll experience powered by Lenis
- 🎬 Preloader with brewing animation
- 🌙 Dark theme with accent colors
- 📱 Mobile-optimized layout

## Technology Stack

- Pure HTML/CSS/JavaScript (no dependencies except Lenis and Three.js)
- Responsive design with mobile-first approach
- CSS custom properties for theming
- WebGL animations with Three.js

## Pages

- **Hero**: Engaging landing section with CTA
- **Menu**: Interactive card-based menu showcase
- **Locations**: Map dial with location information
- **Philosophy**: Brand story with animated background
- **Order**: Call-to-action for online orders
